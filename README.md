# HANA云听听

这是一个简单的音乐播放器。扫码登录后可以播放与缓存歌曲。点封面打开完整页面，点歌曲名进播放列表，点歌手进搜索，点专辑进专辑。

## 简介

HANA云听听是运行在 HANA 里的音乐播放器，通过你自己账号的音乐服务收听。它不只是一个播放条：在聊天时有一条歌词带子跟在输入框上方，点开卡片有完整的播放页，侧栏还有一块常驻的小面板，三处共用同一份播放状态。

它是非官方客户端，与网易云音乐无任何关联；只访问你账号本来就能听的内容，音乐、歌词、封面的版权归各自的权利人。

声音有两种出法。默认走「界面播放」，直接由页面出声，跟随系统默认输出；需要更好的音质或绕开虚拟声卡时，可以切到「MPV 高保真」，由本机的 mpv 进程直接点名声卡输出，支持 WASAPI 独占。

歌曲可以在线听，登录后也可以开启「播放时自动缓存」，把正在听的歌留一份到本地，断网时照样能播。缓存会顺带存好封面和歌词，歌词支持四种显示方式，从安静的中位一句到唱完碎成雪，可以按心情切换。

## 特色

**四种歌词显示方式（都是水的气质）**

- **傲雪**（傲雪随风）：一句唱完先轻轻膨大一圈，再碎成雪花被同一阵风吹散。
- **居盈**（居中盈满）：正在唱的那句在中间放大，下一句在左、上一句在右，换句时三句一起往前推一格。
- **行云**（行云流水）：整段歌词从左往右流过，正中的一句最大最亮，两头淡出。
- **尽染**（层云尽染）：逐字上色，墨一层层化开；有逐字时间轴的歌能跟着唱，没有的按行匀速推进。

四种循环切换的顺序也是这一个。

网易云自己没给逐字的歌，会再去 [AMLL TTML DB](https://github.com/amll-dev/amll-ttml-db) 问一次（那个库按网易云 ID 收录、时间轴校的是同一版音源）；命中就用，没命中就按行。取回来的会缓存，下次不再联网。

**聊天时也看得见歌词**

歌词带子挂在输入框上方，可以一次挂在最近活跃的几个会话里。单击切换显示方式，右键收起；字号四档，配色六档，字体可以在 HANA 字体、系统字体和自己导入的字体之间选。

**两个后端，各有各的用法**

「界面播放」开箱即用；「MPV 高保真」适合接了解码器或需要独占声卡的场合，可以指定输出设备，设备被拔掉或独占打不开时会自动降级并把原因写在界面上。

**缓存与本地库**

登录后在播放器下方打开「播放时自动」，之后播放的歌会按选定音质（标准 / 320K MP3 / 无损 FLAC / Hi-Res FLAC）留一份。音频平铺放在缓存目录里，封面、歌词、曲目信息按同名收在「封面歌词」子文件夹，别的播放器直接扫也能认。缓存目录可改，改完旧目录里的歌不会自动搬。未登录时这个开关不可用——匿名状态下服务只给最低音质。

**外观跟着主题走**

正在唱的那句取界面主色，两侧与未唱部分取同温度的灰，深浅随主题变化；也可以手动选六种配色之一。

## 用法

**第一次使用**：装好后打开卡片，点「登录」用网易云 App 扫码。登录后会解锁完整音质与完整曲目。如果打开后搜不到歌，整页顶部会出现一条提示，点「环境」按清单补齐取源服务（可选再装 mpv）。

**三个入口**

- 全站导航里的「云听听」：完整页面，播放、搜索、歌单、歌词、缓存、本地都在这里。
- 侧栏面板「正在播放」：不打开整页也能控制播放、看进度、切歌。
- 聊天输入框上方的歌词带子：跟着当前会话走。

**点哪里会发生什么**

- 点封面：打开完整页面。
- 点歌曲名：进入播放列表。
- 点歌手：进入搜索。
- 点专辑：进入专辑。

**页签**：播放列表（队列）、搜索、歌词、云歌单、本地。

**播放控制**：上一首 / 播放暂停 / 下一首、进度拖动、音量、循环（顺序 / 列表 / 单曲）、随机。队列里可以拖动排序，每行右侧有红心。

**歌词**：整页的「歌词」页签显示当前曲目的词，有逐字时间轴时会标出来。带子那颗「歌词」钮单击切档，右下角淡「A」切字号，旁边的色点切配色。

**缓存**：播放器下方一行是「缓存 · 播放时自动」开关与音质选择；队列、搜索结果、歌单里每行也有一颗缓存钮。缓存目录可以改，改完旧目录里的歌不会自动搬。

**本地**：「本地」页签列出缓存目录里的音频，点一首就从这批开始放；本地歌曲不需要联网，也不需要登录。

**MPV**：在播放器设置里把后端切到「MPV 高保真」，可选输出设备与独占。界面上会显示实际使用的设备，发生回退时会写明原因。
